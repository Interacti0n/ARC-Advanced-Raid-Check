v1.6.0 CHANGES
  - Added optional raid-session reports with attendance, AFK time, ready-check
    snapshots, boss pulls/kills, first deaths and copyable results.
  - Added estimated trash inactivity. After 10 seconds without combat activity,
    the full inactive interval is counted until the player participates again.
  - Added the READY TO PULL / NOT READY / CHECK INCOMPLETE raid verdict.
    Offline, dead and AFK players are clearly shown as pull blockers.
  - Added a scrolling, screen-aware 25-player roster and visible inspect progress.
  - Added five-minute flask/food warnings and one concise Remind whisper
    containing every confirmed personal issue.
  - Added ARC version comparison; outdated clients now show a red Old marker.
  - Reduced expensive roster rescans while keeping important state and aura
    changes responsive.

v1.5.0 CHANGES
  - Renamed the addon to Advanced Raid Check. The `ARC` folder, commands,
    settings and communication prefix remain compatible.
  - Added standalone ARC Check from inspect, player menus, roster rows and
    `/arc check`. Reports show player details and only problems/unverified data.
  - Added item icons with native tooltips and upgrade-aware snapshot refreshes.
  - Expanded PvE gear validation for MoP gems, enchants, primary stats, PvP
    effects, missing slots and configurable minimum item level.
  - Added empty-talent-tier and class self-buff checks.
  - Added tank stance/form, Righteous Fury, required pet, Warlock Sacrifice,
    Hunter Growl autocast, Shaman weapon imbue and Healthstone checks.
  - Added the raid setup banner for expected difficulty, size and loot method.
  - Added manual-only window opening, Ready/Not Ready buttons and an exact
    numeric minimum-ilvl setting.
  - Added backward-compatible ARC reports for private data and safer handling
    of stale inspect results, changed targets and cached old TOC file lists.
