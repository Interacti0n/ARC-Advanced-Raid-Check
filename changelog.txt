v1.9.0 CHANGES
  - Added Connection Health through the existing ARC column: color reflects
    latency, averaged FPS and report age; hover shows values and ARC version.
  - Uses a compact backwards-compatible H1 extension on existing reports.
    Unknown data stays neutral; no alerts or readiness blockers are added.

v1.8.0 CHANGES
  - Added a required filled Living Steel Belt Buckle socket on raid-level belts;
    its gem uses the same top-tier MoP PvE stat and no-PvP policy as all gems.
  - Added strict normal and legendary meta-gem suitability for STR, AGI, INT,
    healer and tank specs; tanks may use their physical DPS meta and healers may
    use caster metas.
  - Added compact profession reporting between ARC clients and local profession
    detection for self-checks.
  - Added reliable profession gear checks for Blacksmithing sockets,
    Jewelcrafting Serpent's Eyes, Enchanting rings, Leatherworking fur linings,
    Tailoring embroideries and Inscription shoulder bonuses.
  - Visible profession-only gems, cogwheels and enchants are validated directly;
    unavailable or unsafe-to-infer bonuses do not create false failures.
  - Added a versioned ARC_DB schema with guarded, incremental migrations that
    preserve legacy settings, session history and unknown newer-version data.
  - Hardened addon-channel reports with a 255-byte send guard, protected server
    calls and duplicate suppression while retaining the 15-second heartbeat.
  - Added a player-grouped Loot tab to raid sessions with chronological boss
    rewards, bonus items, empty bonus rolls and epic-only trash drops.
  - Kept post-kill loot under the last defeated boss until the next encounter;
    once trash starts, only epic drops are retained to avoid mislabeling delayed
    boss or master-loot awards as trash.
  - Preserved exact item links for hover tooltips and Shift-click, with best-effort
    Heroic, Raid Finder, Flexible, Warforged and Thunderforged labels.
  - Added sender-bound L1 bonus-roll sync, duplicate suppression, a 500-entry
    session cap and a lossless session-schema v3 migration.

v1.7.0 CHANGES
  - Rebuilt Session Report as sortable Players, expandable Bosses and compact
    Export views with a persistent raid summary.
  - Added automatic raid-instance sessions with wipe/reload continuity, a
    30-second exit grace and a manual override in Options.
  - Improved trash tracking: five-second inactivity, combat-log pack detection,
    prompt enemy-death cleanup and a six-second stuck-combat fallback.
  - Pet combat can keep a pack visible but never credits its owner as active.
  - Added offline time, eligible-trash percentages, longest idle streak and
    boss/trash/other/first-death totals; removed stored AFK and ready details.
  - Retains completed sessions for fourteen days, then removes them permanently.
  - Added a visible session-history position and confirmed deletion of saved
    reports; corrected the session help text to describe trash inactivity.
  - ARC Check now supports your own character through local APIs without using
    Blizzard's inspect request.
  - Removed consumable, repair and Healthstone readiness from standalone ARC
    Check so the report stays focused on gear and character requirements.
  - Added class armor-type validation and a confirmed missing off-hand check for
    one-handed main weapons.
  - Added an ElvUI-compatible ARC Check button to the Character Info header.
  - Hardened remote aura, specialization, item, gem and tooltip reads against
    private-server API errors; failed data now remains Unverified/Pending.
