v1.6.0 CHANGES
  - Added opt-in raid session reports with attendance, join/leave time, observed
    AFK duration, boss pulls/kills/durations, first deaths, ready-check snapshots,
    trash-combat time, pull participation and selectable text export.
  - Added strict estimated trash inactivity: after 10 seconds without damage,
    healing, successful casts, interrupts or dispels, the complete inactive
    interval (including its first 10 seconds) is counted until activity resets it.
    Visible pet actions credit their owner; dead/offline players are excluded.
  - Active sessions survive reload; ten completed compact reports are retained.
    Added main/options buttons, /arc session start|end, legacy combat-log handling,
    ElvUI styling, storage/event limits and explicit false-positive documentation.
  - Added immediate AFK tracking through PLAYER_FLAGS_CHANGED. AFK players show
    `(afk)`, receive an amber row state and count as confirmed pull blockers.
  - Turned the top banner into a combined raid verdict and setup check:
    READY TO PULL, NOT READY with confirmed player count, or CHECK INCOMPLETE
    for unverified data. Confirmed failures take priority without hiding setup.
  - Added a vertically scrollable raid roster and screen/scale-aware height cap.
    All 25 players remain available without the window extending off-screen.
  - Reworked live refreshes: ready/dead/offline/range state remains one-second,
    aura changes update immediately, and expensive full-roster aura/gear work
    now uses a five-second fallback instead of running every second.
  - Added visible inspect progress with scanned, waiting and unavailable counts.
  - Added numeric ARC version comparison. Outdated peers show a red Old marker,
    the summary counts them and the tooltip shows the required update version.
  - Added five-minute flask/food expiry warnings. Expiring icons turn amber and
    appear in raid totals, player checks, announcements and private reminders.
  - Expanded Remind to one concise whisper containing every confirmed personal
    issue: consumables, gear, talents, class/tank/pet readiness and Healthstone.
    Unknown or unavailable checks are never presented as failures.
  - Added regression coverage for 25-player layout, refresh throttling, expiry,
    reminders and old/equal/new/malformed ARC versions.

v1.5.0 CHANGES
  - Renamed the addon to Advanced Raid Check across metadata, window/options
    titles, minimap tooltip and documentation. The ARC folder, /arc commands,
    ARC_DB settings and ARC1 communication prefix remain unchanged; no migration.
  - Expanded Tal to Talents in the roster, summary and help, widened its column,
    and removed the available-tiers/no-glyph parenthesis from the row tooltip.
  - Added actual item icons before problem-item names in the standalone check.
    Hover shows the native tooltip for the captured full item link, preserving
    gems, enchant and upgrade fields without querying a changed target.
    Empty slots have no icon; reused rows and closing the window clear tooltips.
  - Added regression coverage for icon layout, full-link tooltip snapshots,
    target changes, row reuse/cleanup, missing icon data and tooltip API failures.
  - Added spec-based tank preparation checks: Protection paladin Righteous Fury,
    Blood DK Blood Presence, Protection warrior Defensive Stance, Guardian Bear
    Form and Brewmaster Stance of the Sturdy Ox. RF on Holy/Retribution is an
    error. Hidden form auras require a fresh same-spec owner report, not guesswork.
  - Added required living pets for hunters, Frost mages and Unholy DKs. Warlocks
    with Grimoire of Sacrifice require its active buff; other builds require a
    pet. Talent choice comes from matched inspect or current ARC data.
  - Added hunter Growl AUTOCAST detection through the full pet spellbook, with
    an action-bar fallback. Only fresh same-pet-GUID ARC reports can flag ON;
    unseen remote pets and unavailable autocast data remain unverified.
  - Added an HS column for reported Healthstone charges, missing-item totals
    and direct standalone findings. Applies to our group with an online warlock;
    excludes the bank, does not infer cooldown and needs the owner's updated ARC.
  - Extended readiness messages with backwards-compatible P1 pet/Growl,
    Sacrifice choice, Healthstone and stance data. Added pet/bag/stance refresh
    events and 30-second report expiry; no automatic character/pet actions.
  - Expanded tests and release notes for legacy pet/stance API tuples, talent
    choice versus buff, same-pet/spec binding, expiry, Healthstone charges and UI.
  - Added a prominent clickable raid-setup banner: red actual/expected
    mode/size and loot mismatches, amber unconfigured/unverified state.
    Configure through /arc raid or Options. Uses actual instance difficulty
    inside raids; never changes raid settings, sends chat or forces ARC open.
  - Added Talents/Self roster columns, affected-player totals and detailed report
    sections for empty unlocked talent tiers and missing class self buffs.
    Talents use the original 18-entry MoP API and class unlock levels; glyphs
    are intentionally excluded. Unavailable or stale data is not a pass/failure.
  - Added level-90 lethal-poison, spec-aware shaman shield, priest Inner buff,
    grouped druid Symbiosis, mage armor and paladin seal presence checks.
  - Added self-reported shaman temporary weapon-imbue presence using the legacy
    three-values-per-hand API. Exempts shields/offhands; no enchant-ID claim.
    A backwards-compatible readiness extension shares talents and imbue state.
    Group reports refresh every 15 seconds while hidden, retaining the 2-second
    throttle. Missing/older peers and expired reports remain unverified.
  - Expanded regression coverage for raid setup UI/events/settings, talent
    unlocks and cache failures, class rules, legacy weapon tuples and comms.
  - Added ARC Check to player right-click menus (target/focus, party/raid and
    standard-menu ElvUI frames) and ARC's own roster row menu.
    Opening menus sends no inspect request; unavailable players are disabled.
    Clicks revalidate the captured player GUID and range. Name-only menus
    require an exact known name/realm, never an unrelated current target.
  - Added context-menu regression coverage for duplicate hooks, submenus,
    unavailable/replaced players, name/realm resolution and existing row actions.
  - Moved ARC Check inside the inspect title bar, left of Close. The compact
    button reserves title space and no longer hangs below the inspect tabs.
  - Simplified standalone checks: ordered player overview, gear verdict, only
    problem slots with explicit reasons, and separate Unverified/Readiness
    sections. Removed healthy item rows, zero counters and passive buff clutter.
  - Added shared raid/standalone PvE validation for MoP rare-or-better gems,
    incorrect primary stats, PvP power/resilience and PvP-oriented meta effects.
    Supports Perfect cuts, profession/legendary gems and known meta proc roles.
  - Added explicit top-tier enchant rules with lower-rank/PvP detection and
    profession, runeforge, scope, shield and caster off-hand handling.
    Equivalent PvE effects are allowed regardless of cosmetic PvP provenance.
  - Resolve actual gem items with GetItemGem instead of treating legacy item-link
    gem fields as item IDs. Check inserted gems in additional sockets as well.
  - Keep gem-cache retries separate from equipped ilvl. Unknown/uncached
    validations no longer produce green OK; raid tooltips explain each finding.
  - Corrected hunter ranged weapon weighting in estimated equipped ilvl.
  - Documented the PvE policy and bundled WoWSims catalog source/MIT notice.
  - Guarded player-check entry points when an in-session update retains an old
    TOC and omits ARC_PlayerCheck.lua. Show a restart/reinstall message instead
    of nil-method errors on load, world entry, update ticks or /arc check.
    The raid UI remains available; a full client restart loads the new module.
  - Corrected upgrade instructions to require a full WoW restart for new files.
    Tests now load ARC.toc and cover the cached-TOC/missing-module case.
  - Added a saved manual-only opening mode in Options and /arc manual [on|off].
    Ready-check tracking and the standard Blizzard prompt remain available.
  - Added ElvUI-compatible Ready / Not Ready buttons at the top-right of ARC,
    enabled only for a pending, unexpired ready check on the local player.
  - Replaced the minimum-ilvl slider with an exact numeric field (400-600).
    Enter/Apply saves; Escape cancels; invalid input preserves the old value.
    Threshold changes invalidate raid gear checks and mark old detail snapshots.
  - Added ARC Check in the Blizzard inspect title bar and /arc check for players
    outside the group. The other player does not need ARC installed.
  - Added a standalone ElvUI-compatible, scrollable problem report with identity,
    spec, gear-check totals and explicit details for affected slots.
  - Pinned reports to player GUIDs, with snapshot age and a same-player Refresh
    action; strangers are never inserted into the raid roster.
  - Coordinated manual and background inspect requests, with range checks,
    timeouts and safe cancellation when another addon replaces inspect data.
  - Incomplete item caches no longer produce a passed check or partial iLvl.
    Filled socket counts remain available even before gem names are cached.
  - Added mocked Lua regression coverage for inspection, reports, manual mode,
    ready-check responses and numeric settings validation.

v1.2.1 CHANGES
  - Split the monolithic Lua implementation into Core, Inspect, UI, Options,
    and Events/Commands modules with an explicit TOC load order.
  - Added README.md with installation, usage, limitations, file layout, and a
    quick in-game verification checklist.
  - Fixed raid-buff source tooltips so they deduplicate and show the actual

  - Synchronized the TOC and runtime versions and stopped hiding UI init errors.

v1.2.0 CHANGES
  - Minimap button (left-click toggles the window, right-click opens
    options, drag to reposition). Hand-rolled with no external library.
  - Hovering the Stam/Stat/Crit/Mast column headers now lists exactly who
    in the raid is providing that buff and with which spell.
  - Right-click any player row for a menu: Whisper, Inspect, or Remind
    (sends them a whisper listing their missing flask/food).
  - A proper Interface Options panel (/arc options) for auto-hide, lock,
    minimap button visibility, and window scale, alongside the existing
    slash commands.
  - Fixed ElvUI skinning: it previously wrapped the whole skin attempt in
    one pcall, so if a minor widget (close button, announce button) failed
    to skin, the working main-frame skin was discarded and silently
    replaced with the default look. Each piece is now skinned and confirmed
    independently, so a minor failure no longer undoes a successful one.

v1.1.0 CHANGES
  - Header/row columns now share ONE layout table, so labels and content
    always line up (this also fixes the "rows overlapping" look - it was
    really a header/row misalignment plus a too-tight ROW_HEIGHT).
  - Full-length column labels: "Flask", "Food", "Stam", "Stat", "Crit", "Mast".
  - Mouseover tooltip now shows the EXACT flask/food buff text (e.g. the
    real "+300 Intellect and 300 Stamina" line), scanned live off a hidden
    tooltip only when you hover a row (no extra per-second overhead).
  - Window title shows a live ready-check countdown, such as
    "(13 seconds remaining)", and switches to "(Finished)" once the check ends.
  - The initiator of a ready check is forced to show the "ready" check icon
    immediately; everyone else shows "?" (waiting) until they respond, and
    anyone still unanswered when the check ends is locked to the "X"
    (not ready) icon so results stay visible.
  - The window no longer auto-closes a few seconds after the ready check
    ends. Instead it hides the moment you enter combat (PLAYER_REGEN_DISABLED,
    i.e. the pull), controlled by the same /arc autohide toggle (default ON).
  - Optional ElvUI skinning: if ElvUI is loaded, ARC reskins its frame,
    close button, and "Announce Missing" button using ElvUI's own Skins
    module, so it matches your ElvUI look automatically.
